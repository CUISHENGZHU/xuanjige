# 玄机阁 · 五术排盘

一个纯前端的传统术数排盘工具，打开网页即可用，**所有推演都在浏览器本地完成，不联网、不上传任何数据**。

在线地址：<https://cuishengzhu.github.io/xuanjige/>

## 功能

| 术数 | 排盘内容 |
| --- | --- |
| **梅花易数** | 时间起卦（农历年月日时）、数字起卦、文字起卦；本卦／互卦／变卦、体用生克、吉凶判词与断法详解 |
| **六爻纳甲** | 三枚铜钱摇卦（可随机或手动指定六次背数）；八宫归属、世应、纳甲干支、六亲、六神、旬空、动爻变爻、用神旺衰与断卦提示 |
| **奇门遁甲** | 时家奇门·转盘·拆补法定局；地盘三奇六仪、天盘九星、八门、八神、十干克应格局、旬空驿马、用神落宫与方位 |
| **四柱八字** | 四柱干支、十神、地支藏干、纳音、五行分布、日主强弱与喜忌、大运排列 |
| **小六壬** | 月／日／时三次起课，大安、留连、速喜、赤口、小吉、空亡六位定吉凶 |

另附「详解」栏目：八卦五行基础、各派起卦与断卦方法、占卜分寸。

## 技术说明

- 纯静态：`index.html` + `css/style.css` + `js/*.js`，无构建、无依赖安装，可直接双击打开或用任意静态服务器托管。
- 农历、节气、干支、旬空、纳音、大运由 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT）提供，精度经春节日期与节气时刻校验。
- 六爻八宫世应、纳甲、六亲、六神，梅花互卦变卦与体用生克，奇门定局与转盘旋转，均为本项目自行实现。

### 算法取舍

- **换日**：日柱以子正（23:00）换日，时干由日干五鼠遁推得。
- **奇门定局**：用拆补法（符头定三元），与置闰法所得偶尔不同，属流派差异。
- **奇门中宫**：中五宫寄坤二宫，天盘不布中宫之干。
- **八字旺衰**：按月令加权的计分速算法，仅供入门参照。

## 本地运行

```bash
git clone https://github.com/CUISHENGZHU/xuanjige.git
cd xuanjige
python3 -m http.server 8080
# 打开 http://localhost:8080
```

也可直接用浏览器打开 `index.html`（脚本为普通 `<script>`，无需服务器）。
