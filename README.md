# 玄机阁 · 五术排盘

一个纯前端的传统术数排盘工具，打开网页即可用，**所有推演都在浏览器本地完成，不联网、不上传任何数据**。

在线地址：<https://cuishengzhu.github.io/xuanjige/>

## 功能

| 术数 | 排盘内容 |
| --- | --- |
| **梅花易数** | 时间起卦（农历年月日时）、数字起卦、文字起卦；本卦／互卦／变卦、体用生克、吉凶判词与断法详解 |
| **六爻纳甲** | 三枚铜钱摇卦（可随机或手动指定六次背数）；八宫归属、世应、纳甲干支、六亲、六神、旬空、动爻变爻、用神旺衰与断卦提示 |
| **奇门遁甲** | 时家奇门·转盘·拆补法定局；地盘三奇六仪、天盘九星、八门、八神、十干克应格局、旬空驿马、用神落宫与方位 |
| **四柱八字** | 四柱干支、十神、地支藏干、纳音、五行分布、日主强弱与喜忌、大运排列 |
| **小六壬** | 月／日／时三次起课，大安、留连、速喜、赤口、小吉、空亡六位定吉凶 |

梅花与六爻的结果页还并置两重解读：

| 视角 | 内容 |
| --- | --- |
| **高岛易断** | 按高岛吞象《高岛易断》体例：卦之气运、占事所宜、要爻之机、十二消息卦，并对动爻作「当位／得中／相应／比／承乘」的爻位分析，合六位通义（初难知、二多誉、三多凶、四多惧、五多功、上易知）定轻重 |
| **曾仕强 · 卦中智慧** | 每卦一句要旨加一段义理，落到「三才」（初二为地、三四为人、五上为天）与「时、位、中、应」，强调易经是讲道理而非算命 |

另附「详解」栏目：八卦五行基础、各派起卦与断卦方法、高岛爻位法、曾仕强的易理与占卜观、占卜分寸。

## 六十四卦详解（教学版）

独立页面 `xue.html`，为自学与背记而做，不含起卦，只讲卦：

| 模块 | 内容 |
| --- | --- |
| **逐卦详解** | 卦辞与大象传原文＋白话；曾仕强式义理（要旨、义理、点拨）；高岛易断三栏（气运／占事／要爻）；一句话记忆钩子 |
| **六爻位** | 逐爻列当位、得中、相应、比与承乘，给出吉／偏吉／平／偏凶／凶的轻重，点任一爻直接跳到它变出的卦 |
| **卦变** | 错卦（六爻全反）、综卦（整卦倒置）、互卦（二三四／三四五爻），以及六个单爻变的变卦 |
| **对照表** | 八卦符号速记（乾三连……）、上下卦 8×8 组合表、京房分宫卦象次序（八宫各八卦） |
| **卦序歌** | 朱熹《上下经卦名次序歌》七句，每句下附对应卦的直达入口，另给三条背卦捷径 |
| **自测** | 看卦符猜名／看卦名猜符／看卦辞猜卦，四选一即时反馈，优先考没记住和错得多的；掌握进度存本地 |

入口在首页标题下方「六十四卦详解 · 教学版 →」。

白话与点拨均为按曾仕强讲易之旨、高岛易断体例所作的**改写**，不是原文引用；卦辞、大象传为经典原文。所有卦象用 CSS 线条绘制，不依赖字体是否含易卦图符。

## 技术说明

- 纯静态：`index.html` + `css/style.css` + `js/*.js`，无构建、无依赖安装，可直接双击打开或用任意静态服务器托管。
- 农历、节气、干支、旬空、纳音、大运由 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT）提供，精度经春节日期与节气时刻校验。
- 六爻八宫世应、纳甲、六亲、六神，梅花互卦变卦与体用生克，奇门定局与转盘旋转，均为本项目自行实现。

### 算法取舍

- **换日**：日柱以子正（23:00）换日，时干由日干五鼠遁推得。
- **奇门定局**：用拆补法（符头定三元），与置闰法所得偶尔不同，属流派差异。
- **奇门中宫**：中五宫寄坤二宫，天盘不布中宫之干。
- **八字旺衰**：按月令加权的计分速算法，仅供入门参照。
- **高岛易断与曾仕强**：两栏均为按各自体例／讲授思路所作的**整理概括**，不是原书断辞或讲课录音的原文引用；书中逐爻断辞与大量占例，仍须读原著。

## 本地运行

```bash
git clone https://github.com/CUISHENGZHU/xuanjige.git
cd xuanjige
python3 -m http.server 8080
# 打开 http://localhost:8080
```

也可直接用浏览器打开 `index.html`（脚本为普通 `<script>`，无需服务器）。
